# SQL Studio · Simulador Interactivo de Base de Datos

Simulador educativo interactivo para aprender diseño e ingeniería de bases de datos relacionales en MySQL, basado en las consignas de la materia **Algoritmos II (Analista de Sistemas de Información)** del **Instituto Argentino de la Empresa** (Prof. Lic. Adrián Aroca).

## 🚀 Acceso en Vivo
Puedes acceder a la versión web portable en vivo aquí:
👉 **[https://rax0r-cmd.github.io/sql_practice/](https://rax0r-cmd.github.io/sql_practice/)**

## ✨ Características Principales
- **100% Portable y Autónomo:** Funciona directamente en cualquier navegador sin necesidad de instalar ni configurar XAMPP, Apache, PHP ni MySQL.
- **Motor Embebido en Memoria:** Ejecuta `CREATE TABLE`, `INSERT`, `VIEW`, `FUNCTION`, `PROCEDURE`, `TRIGGER` y `CURSOR` en JavaScript puro con validación paso a paso.
- **Diagrama Entidad-Relación (DER) en Vivo:** Genera automáticamente el diagrama relacional con nodos interactivos y líneas de conexión entre claves foráneas.
- **Grilla de Datos en Tiempo Real:** Visualización instantánea de registros al insertar filas.
- **Desglose Didáctico:** Cada uno de los 12 niveles cuenta con el pedido oficial de la Cátedra, el enlace mental de cómo pensarlo, el desglose línea por línea y la solución colapsable.
